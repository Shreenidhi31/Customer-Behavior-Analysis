# Customer Behavior Analysis

This project analyzes customer shopping behavior using Python, PostgreSQL, SQL, and Power BI. The goal is to understand customer spending, subscription behavior, product preferences, discounts, and purchasing patterns.

## Tools Used
- Python
- MySQL/SQL
- Power BI
- Pandas

## Analysis
The project covers:
- Customer spending and revenue analysis
- Subscriber vs. non-subscriber behavior
- Customer segmentation based on purchase history
- Product ratings and purchasing trends
- Discount and shipping analysis
- Revenue by customer demographics

## Key Findings
- Analyzed 3,900 customer transactions.
- Identified 3,116 Loyal, 701 Returning, and 83 New customers.
- Subscribers generated $62.6K in revenue, while non-subscribers generated $170.4K.
- Gloves had the highest average product rating at 3.86/5.
- Express shipping had an average purchase value of $60.48 compared with $58.46 for Standard shipping.
